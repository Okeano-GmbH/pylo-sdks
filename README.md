# Pylo SDKs

TypeScript SDKs for building applications with Pylo.

| Package | For |
| --- | --- |
| [`@pylo/react`](./react) | React single-page apps, such as Vite |
| [`@pylo/expo`](./expo) | Expo and React Native |
| [`@pylo/nextjs`](./nextjs) | Next.js, with tokens in httpOnly cookies |
| [`@pylo/node`](./node) | Servers and Pylo flow actions |
| [`@pylo/core`](./core) | The shared client, type system and codegen |
| [`@pylo/auth`](./auth) | Token and GraphQL primitives |

Every package generates its types from your own Pylo schema with `pylo generate`.
